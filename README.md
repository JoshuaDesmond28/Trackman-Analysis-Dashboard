# Project Title

Trackman Pitching Analysis Dashboard

## Description

This project takes a CSV file from Baseball Savant and displays the metrics and details in a variety of charts for different aspects of the game. These include pie, bar, spray, and heatmap charts for pitchers who played that game. A machine learning model will analyze the program and make predictions on where future pitches can go and how hitters will fair against them as well as recommendations for improvement.

## Getting Started

### Installing

* All Files are required to run this program

### Executing program

* This program runs locally on the computer
* simply execute the html file and this will prompt the program to start
* upload the csv file you wish to analyze
* the program will execute and give detailed results
## Help

This program is designed around a csv from baseball savant. If the structure of your csv is not similar then the program will crash.
